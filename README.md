# 中华教育网发稿助手

这是一个 Chrome/Edge 扩展，用来把 QQ 发来的稿件消息自动发布到中华教育网后台，并生成回传消息。

给老妈减轻工作负担的小项目，也是我用 Codex 做的第一个小项目。

## 当前流程

1. 在扩展页粘贴 QQ 消息，格式类似：

   ```text
   北京公共营养师培训机构排名（全链路赋能与就业变现专项榜）
   https://v.gaoduanedu.cn/news/512026060417383810669556272
   中华教育网
   ```

2. 点击“开始转载”。
3. 扩展会打开稿源页，自动识别正文；如果页面只是标题和二级链接，会继续跟随链接，最多 3 层。
4. 如果后台未登录，扩展会自动填写已配置的后台账号密码并登录。
5. 扩展会打开中华教育网后台，填入标题和正文。
6. 扩展会自动点击后台“增加”。
7. 如果后台弹出“增加成功”等提示，扩展会自动确认。
8. 发布成功后，扩展会去中华教育网官网按刚刚发布的完整标题搜索，并从搜索/首页结果里精确匹配标题，复制对应的最新 `/edu/数字.html` 链接：

   ```text
   北京公共营养师培训机构排名（全链路赋能与就业变现专项榜）
   http://www.edu-gov.cn/edu/27150.html
   中华教育网
   ```

## 安装方式

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择目录：`C:\Users\36014\codex-edugov-helper`。
5. 每次修改扩展代码后，需要在扩展管理页点击“重新加载”。

## 手机控制台

### 局域网启动

```powershell
npm.cmd run mobile
```

启动后终端会打印手机可访问地址，例如：

```text
Open on phone: http://192.168.1.23:8787
```

局域网测试时，手机和电脑连同一个 Wi-Fi 后可直接打开这个地址。真正外出只带手机时，需要再配 Cloudflare Tunnel、ngrok、frp 等公网穿透工具，手机打开穿透后的公网地址即可。进入页面后粘贴 QQ 稿件消息并点击“开始发稿”。电脑会自动打开浏览器完成发稿，手机页面会持续显示状态，完成后显示可复制的回传消息。

默认访问密码是：

```text
20050804
```

如果要把服务通过 Cloudflare Tunnel、ngrok、frp 等方式暴露到公网，手机打开公网地址后会先看到登录页，输入该密码后才能进入发稿控制台。

### 公网启动

已经内置 Cloudflare Tunnel 临时公网访问工具。电脑端运行：

```powershell
cd C:\Users\36014\codex-edugov-helper
npm.cmd run public
```

终端会打印类似这样的地址：

```text
https://example-random-name.trycloudflare.com
```

在手机浏览器打开这个 HTTPS 地址，输入密码 `20050804`，即可在外面用手机发稿。

注意：

- 这个临时公网地址每次启动可能会变化。
- 运行窗口不能关闭；关闭后公网地址会失效，电脑端自动服务也会停止。
- 如果想要固定网址，需要再绑定 Cloudflare 账号和域名。

可选环境变量：

```powershell
$env:PORT="8787"
$env:BROWSER_CHANNEL="msedge"
$env:MOBILE_TOKEN="20050804"
$env:KEEP_BROWSER_OPEN="1"
npm.cmd run mobile
```

`KEEP_BROWSER_OPEN=1` 可以让自动化浏览器完成后不关闭，方便调试。

## 说明

- “抓取发布链接”按钮仍保留，作为需要重新复制当前稿件链接时的备用入口；它也会按当前任务标题去中华教育网官网搜索，不再依赖后台列表。
- 点击“开始转载”后，浏览器可能会因为打开/切换页面而自动关闭扩展弹窗，这是正常现象；任务会在后台继续跑，图标角标会显示 `RUN`、`DONE` 或 `ERR`，重新打开扩展会恢复状态和回传消息。
- 正文写入逻辑优先支持 UEditor、TinyMCE、CKEditor、KindEditor、iframe 富文本、contenteditable，最后才同步 textarea。
- `D:\codex\codex-edugov` 当前仍无法写入，所以项目暂时放在用户目录。
